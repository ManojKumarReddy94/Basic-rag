### STEPS TO PRACTICE

1.Install uv package

```
pip install uv
```
2.Create a virtual environment
```
uv venv basicragenv
```
3.Activate the venv
```
basicragenv\Scripts\activate
```

### STEPS FOR GIT AND GITHUB

1. Install the git
2. Make an id on github
3. make a repo on github dont touch anything
4. make a .gitignore file
5. commands 

```
git add .
git commit -m "commit something"
git push
```
